# Craftium Launcher

Craftium is an Android launcher project based on Amethyst-Android, an open-source Minecraft: Java Edition launcher for Android.

- Application ID: `com.craftium.launcher`
- Android module: `app_pojavlauncher`
- Initial upstream branch: `v3_openjdk`
- Build: `./gradlew :app_pojavlauncher:assembleDebug`
- CI: `.github/workflows/android.yml`

The upstream Amethyst/PojavLauncher license and notices are retained. Amethyst is licensed under LGPL-3.0; see the included upstream license files. Craftium branding does not imply ownership of the upstream launcher engine.
